O que significa cada coluna
  • Índice — posição da coluna no arquivo (0 = primeira), editável: digite direto o índice que quiser. Vale -1 para a última coluna (e -2 para a penúltima), ou o nome da coluna quando o arquivo tem linha de cabeçalho. Linha nova já vem com o próximo índice livre. Não pode repetir índice nem usar a coluna do timestamp — o servidor recusa e diz qual é.
  • Rótulo — título do gráfico. Unidade — só exibição na legenda.
  • Tipo — como o valor da coluna é lido: Número (padrão) · Inteiro (sem casas decimais) · Booleano (0/1, também aceita sim/não, true/false, on/off) · Data/hora (epoch) — para as OUTRAS colunas de carimbo do arquivo: a linha mostra quando aquele bloco avançou e os valores aparecem como hora, não como número · Data/hora (texto) — idem, para carimbos escritos por extenso (2026-08-24, 24/08/2026 00:30): o formato é descoberto entre os usuais · Texto — não vira gráfico; a tela mostra o último valor lido.
    Os tipos valem também na pré-visualização: cada coluna mapeada mostra o valor convertido embaixo do valor cru.
  • Mín / Máx físicos — limites plausíveis: viram linhas tracejadas no gráfico e os trechos fora deles ficam vermelhos.
Valores não numéricos (NAN, ±7999) viram lacunas.
