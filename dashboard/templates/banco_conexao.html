Apontar o banco

O teste roda de dentro da imagem da API (tem o driver), com os valores do formulário, sem gravar nada. Requisitos do destino: PostgreSQL 16 com timescaledb e postgis instalados e o schema do CARBONARA (restaure com pg_dump/pg_restore ou promova um espelho); libere a porta para o IP deste servidor.

Roteiro de migração do banco

  1. No servidor novo: PostgreSQL 16 + TimescaleDB + PostGIS (a mesma imagem timescaledb-ha serve). Libere a porta para este servidor.
  2. Copie os dados: pg_dump -Fc carbonara | pg_restore -d carbonara no destino, ou use um espelho (streaming replication com o papel replicator) e promova-o.
  3. Aqui: marque Externo, preencha host/porta/usuário/senha, Testar conexão, Gravar no .env, Aplicar aos serviços.
  4. Confira em Visão geral que os números batem e, só então, Parar banco local.
